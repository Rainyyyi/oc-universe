OC宇宙 - 需求规格说明

一、项目概述

OC宇宙 是一个面向创作者的原创角色（Original Character）全生命周期管理平台。用户可以创建多个世界观，在每个世界观下管理角色、撰写故事、构建关系图谱，并与角色进行 AI 对话。

项目定位：个人/小团队创作工具，兼顾云端协作与离线使用。

二、用户角色

角色 说明
访客（未登录） 可使用本地模式，数据存储在浏览器 LocalStorage，不支持多设备同步
注册用户（已登录） 数据存储在 Appwrite 云端，支持多设备同步与世界观协作
世界观创建者 创建世界观，邀请协作者，管理协作者权限
协作者 被邀请加入世界观，可查看和编辑该世界下的角色、故事等数据

三、功能需求

3.1 用户系统

编号 需求 说明
U-01 邮箱注册 使用邮箱 + 密码 + 昵称注册
U-02 邮箱登录 使用邮箱 + 密码登录
U-03 退出登录 清除当前会话，切换回本地模式
U-04 修改昵称 登录后可在设置中修改昵称，昵称同步到 profiles 集合

U-07 离线可用 未登录时自动切换本地模式，所有功能仍可使用（仅无协作能力）

3.2 首页 - 世界观管理

编号 需求 说明
W-01 宇宙星图视图 Canvas 星空背景 + 世界观行星 + OC 角色轨道粒子，可视化展示所有世界观

W-03 视图切换 星图 ↔ 网格一键切换，平滑过渡
W-04 创建世界观 设置名称、类型（奇幻/科幻/现代/古风/其他）、基调、简介、封面图
W-05 编辑世界观 修改世界观的所有信息，包括封面图上传
W-06 删除世界观 确认后删除世界观及其下所有角色和故事
W-07 行星拖拽 在星图视图中可单独拖拽行星位置（布局个性化）
W-08 视口操作 星图支持鼠标拖拽平移 + 滚轮缩放 + 触摸捏合
W-09 悬浮详情 星图中悬停行星弹出世界观摘要卡片
W-10 行星着色 不同类型世界观用不同颜色：奇幻=紫、科幻=蓝、现代=绿、古风=金、其他=粉

CH-08 批量导入 支持批量导入角色数据

编号 需求 说明

ST-02 编辑故事信息 修改故事基本信息

ED-03 章节操作 新增章节、重命名、删除章节、拖拽排序

五、非功能需求

六、数据需求

6.1 核心数据实体

实体 存储位置 说明
世界观 (Worlds) Appwrite / LocalStorage 创作世界框架
角色 (Characters) Appwrite / LocalStorage 原创角色信息
故事 (Stories) Appwrite / LocalStorage 故事及章节内容
关系 (Relations) Appwrite / LocalStorage 角色间关系连线
聊天 (Chats) Appwrite / LocalStorage AI 聊天历史
灵感 (Inspirations) Appwrite / LocalStorage 灵感碎片
设置 (Settings) Appwrite / LocalStorage 用户偏好设置
档案 (Profiles) Appwrite 用户昵称缓存（仅云端）

6.2 存储策略

  • 已登录：数据读写 Appwrite Database，文件存储 Appwrite Storage
  • 未登录：数据读写浏览器 LocalStorage
  • 昵称：通过 Appwrite Profiles 集合缓存，协作者/创作者处查询显示
